# ResuMatch AI

ResuMatch AI is a web application that helps users compare their resumes with a job description and understand how well they match an ATS (Applicant Tracking System).

I built this project to improve my React skills while creating something that solves a real-world problem. The application provides an ATS score, keyword analysis, resume insights, and a simple dashboard to help users understand where they can improve their resumes.

## Features

- Upload a resume
- ATS score based on resume and job description
- Keyword matching analysis
- Resume strength overview
- Interactive dashboard
- Responsive UI with dark mode

## Tech Stack

- React
- Vite
- JavaScript
- Framer Motion
- Recharts
- Lucide React
- CSS
